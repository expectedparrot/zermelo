# Zermelo examples

- [Ten blog experiments](blog_series/README.md): original books, product features,
  library programs, names, film pitches, programming projects, conference talks,
  opening paragraphs, museum exhibits, and blog ideas. Demonstrates native ranker
  panels, calibration, follow-ups, incremental entrants, sensitivity, alternative
  ranking methods, and the agent workflow.
- [States to visit](states_visit/README.md): the preserved 50-state worked example
  behind `docs/index.html`.
- `entrants.csv` and `agent_list.ep`: the small fictional product-improvement study
  used in the package README.
- `test-model.json`: a canned five-option answer for free local execution checks.

Keep generated projects under `runs/`. Preparing or exporting examples never
submits inference; execute exported jobs separately through `ep run`.
